# Catalogue de la librairie des blocs neutres.
#
# Un bloc par ligne, 5 champs séparés par " | " :
#   chemin (depuis blocs-neutres/) | titre | typologies (séparées par " ; ") | étiquettes (séparées par des virgules) | description
#
# - L'ordre des lignes est l'ordre d'affichage.
# - Les typologies s'affichent dans l'ordre de leur première apparition ici.
# - Un bloc qui relève de plusieurs typologies les liste toutes, séparées par un point-virgule : il apparaît dans chacune,
#   avec la mention « Aussi dans ».
# - Ne pas utiliser le caractère "|" dans un champ.
# - Après toute modification (ici ou dans un bloc), relancer : bash librairie/build.sh
#
