Refonte wefiit.com

Librairie des blocs.

Les blocs neutres du site, vides (textes en lorem ipsum, photos et vidéos à venir), rangés par typologie. Chaque bloc est un fichier autonome à coller dans un Embed Webflow : cliquez sur « Copier le code » pour récupérer celui qui vous intéresse. Un bloc qui relève de plusieurs typologies apparaît dans chacune, avec la mention « Aussi dans ».

Les vidéos YouTube peuvent afficher « Erreur 153 » quand cette page est ouverte directement depuis le disque : c'est une limite de YouTube hors d'un vrai site, pas un défaut du bloc. Pour les voir jouer, servir le dossier du repo avec un petit serveur local (par exemple python -m http.server) et ouvrir /librairie/.
